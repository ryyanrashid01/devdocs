# Web Development Resources

A curated collection of tools and resources for modern frontend (and a bit of backend) development.

---

## Design Inspiration
- [Dribbble](https://dribbble.com) — Designer portfolios and UI shots
- [Awwwards](https://www.awwwards.com) — Award-winning creative websites
- [21st.dev](https://21st.dev) — Modern UI component inspiration
- [Godly](https://godly.website) — Curated web design showcase
- [Land-book](https://land-book.com) — Landing page design gallery
- [Lapa Ninja](https://www.lapa.ninja) — Landing page inspiration
- [Mobbin](https://mobbin.com) — Mobile & web UI pattern library

## UI Component Libraries
- [shadcn/ui](https://ui.shadcn.com) — Copy-paste React components built on Radix + Tailwind
- [DaisyUI](https://daisyui.com) — Tailwind CSS component library
- [Radix UI](https://www.radix-ui.com) — Headless, accessible primitives for React
- [MagicUI](https://magicui.design) — Animated components for React & Tailwind
- [Aceternity UI](https://ui.aceternity.com) — Trendy, animated React components
- [HeroUI](https://www.heroui.com) — Modern React UI library
- [Flowbite](https://flowbite.com) — Tailwind component library with Figma kit

## UI Theming & Customization
- [tweakcn](https://tweakcn.com) — Visual no-code theme editor for shadcn/ui; customize colors, fonts, radius in real-time and export CSS variables
- [Realtime Colors](https://www.realtimecolors.com) — Visualize color palettes on a real UI before committing
- [UI Colors](https://uicolors.app) — Generate Tailwind-compatible color palettes
- [Coolors](https://coolors.co) — Fast color palette generator
- [Mesh Gradient](https://meshgradient.in) — Beautiful mesh gradient generator
- [Haikei](https://haikei.app) — SVG blob and background shape generator
