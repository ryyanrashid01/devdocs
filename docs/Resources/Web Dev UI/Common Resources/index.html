Web Development Resources

A curated collection of tools and resources for modern frontend (and a bit of backend) development.

Design Inspiration​

  • Dribbble — Designer portfolios and UI shots
  • Awwwards — Award-winning creative websites
  • 21st.dev — Modern UI component inspiration
  • Godly — Curated web design showcase
  • Land-book — Landing page design gallery
  • Lapa Ninja — Landing page inspiration
  • Mobbin — Mobile & web UI pattern library
  • Uiverse — Community-made open-source UI elements in CSS & Tailwind

UI Component Libraries​

  • shadcn/ui — Copy-paste React components built on Radix + Tailwind
  • DaisyUI — Tailwind CSS component library
  • Radix UI — Headless, accessible primitives for React
  • MagicUI — Animated components for React & Tailwind
  • Aceternity UI — Trendy, animated React components
  • HeroUI — Modern React UI library
  • Flowbite — Tailwind component library with Figma kit

UI Theming & Customization​

  • tweakcn — Visual no-code theme editor for shadcn/ui; customize colors, fonts, radius in real-time and export CSS variables
  • Realtime Colors — Visualize color palettes on a real UI before committing
  • UI Colors — Generate Tailwind-compatible color palettes
  • Coolors — Fast color palette generator
  • Mesh Gradient — Beautiful mesh gradient generator
  • Haikei — SVG blob and background shape generator

AI App & UI Builders​

  • v0 by Vercel — Prompt-to-React UI with Tailwind, deployable instantly
  • Bolt — Full-stack AI app builder in the browser
  • Lovable — Prompt-to-app React builder
  • Aura — AI-powered design templates
  • Builder.io — Visual editor that integrates with any codebase
  • Framer — Visual website builder with a powerful component system

Agentic & AI Coding Tools​

  • Claude — General-purpose AI with strong UI/coding ability
  • Claude Code — Agentic CLI for coding tasks
  • Cursor — AI-native code editor
  • GitHub Copilot — In-editor AI code completion
  • UI/UX Pro Max Skill — AI skill (Claude Code / Cursor) with 50+ design styles, 161 color palettes, 57 font pairings, and 99 UX guidelines for generating professional design systems from prompts
  • CopilotKit — Toolkit for building agentic UI (generative UI, real-time agent interaction)

Fonts & Typography​

  • Google Fonts — Free, open-source web fonts
  • Fontshare — High-quality free fonts from Indian Type Foundry
  • Fontsource — Self-hostable open-source fonts via npm
  • Font Pair — Curated font pairing suggestions
  • Typescale — Generate typographic scales visually

Icons & Illustrations​

  • Lucide — Clean, consistent open-source icon set
  • Heroicons — SVG icons by the Tailwind CSS team
  • Phosphor Icons — Flexible icon family for any project
  • Iconify — Unified icon framework with 200k+ icons
  • Undraw — Open-source SVG illustrations
  • Storyset — Customizable, animated illustrations

Image & Logo Generation​

  • Ideogram — AI image generation with great text rendering
  • Recraft — AI vector & image generation for designers
  • Looka — AI-powered logo maker
  • Midjourney — High-quality AI image generation

CSS & Animation Tools​

  • Tailwind CSS — Utility-first CSS framework
  • Animista — On-demand CSS animation generator
  • Cubic Bezier — Custom easing curve builder
  • Neumorphism.io — Soft UI shadow generator
  • CSS Tricks — Guides, snippets, and references

Design Tools​

  • Figma — Industry-standard UI design and prototyping
  • Google Stitch — AI-native design canvas (text/image/sketch → high-fidelity UI, exports to Figma)
  • Magic Patterns — Generates UI screens aligned to your existing design system
  • Penpot — Open-source, self-hostable Figma alternative

Dev Tooling & Build​

  • Vite — Lightning-fast frontend build tool
  • Bun — Fast all-in-one JS runtime and package manager
  • pnpm — Fast, disk-efficient package manager
  • Turborepo — High-performance monorepo build system
  • Bundlephobia — Check npm package bundle sizes before installing

Backend (Essentials)​

  • tRPC — End-to-end typesafe APIs for TypeScript
  • Prisma — Type-safe ORM for Node.js
  • Drizzle ORM — Lightweight, TypeScript-first ORM
  • Hono — Ultra-fast, lightweight web framework for edge runtimes
  • Supabase — Open-source Firebase alternative (Postgres + auth + storage)

Performance & QA​

  • Lighthouse — Automated performance auditing
  • PageSpeed Insights — Google's performance analyzer
  • Squoosh — Browser-based image compression
  • Can I Use — Browser compatibility tables
  • Carbon — Beautiful code snippet screenshots
